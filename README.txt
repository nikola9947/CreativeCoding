# Factory Balance

A factory simulation game in which players must keep a production line running by repairing broken stations through interactive minigames before time runs out.

## Description

Factory Balance is a Unity game developed as part of the Creative Coding course at Hochschule Ansbach.

The objective is to deliver the required number of pallets before the timer expires. Throughout the game, four different production stations gradually lose vitality. Whenever one of them breaks down, production stops and the player must complete a unique minigame to repair the station before work can continue.

The game combines resource management, quick reactions, and simple skill-based mechanics into a fast-paced factory experience.

### Features

* Three selectable difficulty levels
* Four unique repair minigames
* Fully functional conveyor-based production line
* Dynamic vitality system
* Countdown timer
* Win and lose conditions
* Interactive camera changes during minigames
* Background music with on/off toggle

### Controls

#### General
* **Left Mouse Button** – Interact with buttons and objects

#### Worker Minigame
* Click the fan repeatedly until the recovery bar is full.

#### Machine Minigame
* Adjust the RGB sliders until the displayed color matches the target color.

#### Robot Calibration Minigame
* Press each calibration button while its slider is inside the target area.

#### Pallet Balance Minigame
* **A / Left Arrow** – Move pallet left
* **D / Right Arrow** – Move pallet right

Keep the pallet balanced until the progress bar is full.
